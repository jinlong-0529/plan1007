# 上线准备清单

日期：2026-10-07；当前版本：1.0.0；目标：Windows 10/11 x64。

## 直接发送安装文件

- [ ] 核对 EXE 文件名、版本、SHA256，附带源码、图标、SOP、此清单。
- [ ] 确认发行方名称、支持联系方式和隐私说明；不要把示例开发团队当作正式发布者身份。
- [ ] 在干净 Windows 10 和 11 测试中文向导、安装目录选择、快捷方式、首次运行、卸载与重装。
- [ ] 测试 1024×768、常见缩放与多显示器布局；确认页面无横向滚动。
- [ ] 测试文档导入、关键词检索、状态更新、数据重启保留、日报、DOCX/XLSX/Markdown 导出和备份恢复。
- [ ] 与实际 Plane 实例联调；确认这是单向导入、远端密钥权限和中文错误提示。
- [ ] 运行 Defender 扫描；本次打包不等于已完成反病毒认证。
- [ ] 将 SmartScreen “更多信息 → 仍要运行”说明发给可信接收人；企业阻止策略需管理员审批。
- [ ] 正式对外分发前准备代码签名、支持流程、版本更新策略与依赖漏洞审查。
- [ ] 复核第三方软件许可证与通知。此包未复制 Plane 或 Blinko 代码，未来引入代码需复核其许可。
- [ ] 告知客户本地数据与 JSON 备份没有应用层加密；使用受控账户、BitLocker 和安全备份位置。

## 微软商店：EXE/MSI 路径

该 NSIS EXE 是技术起点；**未签名的当前交付包不能直接视为商店就绪**。

- [ ] 注册并验证 Microsoft Partner Center 开发者账号，预留应用名称。
- [ ] 确认产品身份、发布者、支持邮箱、隐私政策 URL、应用描述、年龄分级、市场与中文截图。
- [ ] 使用受微软信任根计划支持的证书签名安装器及相关 PE 文件，附带有效时间戳。
- [ ] 提供稳定、带版本号、HTTPS 的安装包 URL（不能把本地文件直接作为 URL）。
- [ ] NSIS `/S` 提供静默安装，验证干净机器中的返回码、安装成功、无需交互、依赖随包。
- [ ] 验证正确注册卸载信息、可卸载、无不相关捆绑程序，检查安装/卸载后的数据保留策略。
- [ ] 验证程序不依赖开发机器路径或 Node/MySQL。可选 Plane 功能要求用户自己的服务。
- [ ] 填写安装参数、支持架构与系统要求，并提交审核；接受商店认证结果。

依据：[Win32 应用商店分发](https://learn.microsoft.com/en-us/windows/apps/distribute-through-store/how-to-distribute-your-win32-app-through-microsoft-store)、[分发路径与签名要求](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/choose-distribution-path)、[安装包 URL 要求](https://learn.microsoft.com/en-us/windows/apps/publish/publish-your-app/msi/upload-app-packages)。

## 微软商店：MSIX 路径

- [ ] 在现有应用基础上准备独立 MSIX 打包配置，核对包身份和 Partner Center 保留的发布者身份。
- [ ] 准备 StoreLogo、Square44x44Logo、Square150x150Logo 等对应 Manifest 的资源。ICO 四尺寸不能替代全部商店资源。
- [ ] 设置架构、最低 Windows 版本、版本号、入口和所需能力；使用最小必要权限。
- [ ] 测试文件选择器、用户数据路径、导入导出、包升级及卸载的数据行为。
- [ ] 运行 Windows App Certification Kit，提交包、中文素材和审核说明。

依据：[MSIX 包要求](https://learn.microsoft.com/en-us/windows/apps/publish/publish-your-app/app-package-requirements?pivots=store-installer-msix)。

## 当前交付边界

当前具备可离线运行的个人工作台、本地记录、文件导入导出与可选 Plane 问题快照导入。AI/RAG、Plane 双向写回、自动更新、代码签名、商店发布、真实客户实例验证属于后续事项。上线前必须以实际构建验证报告与干净机器验收结果为准，不能把清单勾选当作已完成认证。
